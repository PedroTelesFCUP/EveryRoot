# Prepared architecture release

EveryRoot: Learning Chess Moves and Search Allocation.

This package describes the implemented learning flow, its relation to existing research and its potential use in a competitive chess engine and application. This is a locally prepared publication package. No public GitHub release has been made and no DOI has been issued or reserved by preparing these files. Publication metadata should be completed with actual identifiers when the release is made.
