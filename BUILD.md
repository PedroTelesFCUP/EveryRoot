# Rebuilding the publication

The editable report is `docs/architecture_report.md`. The figure and PDF are generated by `scripts/build_publication.py`.

From the repository folder, run:

```bash
python -m pip install matplotlib reportlab
python scripts/build_publication.py
```

The script uses the DejaVu fonts shipped with Matplotlib and writes the figure as PNG and SVG, then the report as PDF. It performs no chess search or model training. If the Markdown is edited, inspect the resulting PDF for page overflow before release. Intentional page boundaries are marked in the Markdown source.

The README and Zenodo description are separately edited summaries. If the project title, authorship or architecture changes, update them and CITATION.cff together. The reference list and BibTeX file retain the underlying research credits.
